# UsagePanel Frontend

Interfaz React, TypeScript, Vite y Tailwind de UsagePanel.

El frontend no gestiona credenciales, roles ni sesiones. Consume exclusivamente la API configurada en `VITE_API_BASE_URL` y usa cookies `HttpOnly` emitidas por el backend.

Consulta el `README.md` de la raíz para instalación y ejecución del monorepo.
